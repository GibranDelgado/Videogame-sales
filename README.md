# Videogame sales
Thank you for your interest in my project. This time I decided to use one of the most popular kaggle's dataset which contains information about the best-selling videogames of all times in order to make an exploratory data analysis about how sales were distributed according each year, publisher, genre, region, etc.

## Content
The project has two folders

### Used files
Here, you will find two files: A csv file with the videogame sales information and a txt file with the queries used to analyse the data.

### Scripts
Contains two python scripts.
  - **Scripts:** Script used to read an specific query from the text file mentioned before
  - **Views_creation:** Convert the csv file into a dataframe and then transfer this into a database and tables. Transform every query listed on the queries.txt file into a excel file with the resulting data.

## About the use
Execute the "Main.py" script. This going to create a new folder called "Queries_results", with the resulting files generated by the "Views_creation" script mentioned before.

`If you want to add or modify a query, don't forget to keep the numerology followed in the document. Take in consideration that the dashboard is processing a lot of data in real time, so it's normal if you see a delay in the response of the filters.`

## Results discussion
  - The Mario Bros franchise includes some of the best-selling video games of all time.
  - Nintendo is ranked as the publisher with highest revenues of all times, despite not being one of the publishers with most releases.
  - PlayStation 2 and 3 are considered as the most successful consoles of all time, as they are among one of best-selling consoles of all time and the consoles with most releases.
  - Same phenomenon occurs with genres such as action and sports.
  - For most publishers, PlayStation 2 was the most profitable console, with the years between 2006 and 2008 being the most successful ones.
  - Action and sports videogames dominate the markets in North America, Europe and rest of the world regions; however, Japan is the exception to the rule, where role-playing games are the most successful genre.
  - A similar trend occurs with consoles, as PlayStation 2 and 3, and Xbox 360 are the best-seller in the first three regions mentioned before, but not for Japan, where Nintendo DS dominates the market.

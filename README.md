# 🎮 Videogame Sales
Thank you for your interest in this project. This repository features an Exploratory Data Analysis (EDA) focused on one of Kaggle’s most popular datasets, containing information about the best-selling video games of all time.

## 📖 Overview
The goal of this project is to perform a deep Exploratory Data Analysis (EDA) to understand how global revenue is distributed across years, publishers, genres, and geographic regions. By combining Python automation, SQL querying, and Business Intelligence, this project transforms raw data into strategic insights about the gaming industry's evolution.

## 📂 Project Content
The project is structured into two main directories to separate raw data from processing logic:
### 📄 Used Files
- **CSV file:** The core dataset with historical video game sales.
- **TXT file:** A collection of SQL queries used to perform the data analysis.

### 🏗️ Scripts
#### 🔍 Query_generation
Logic used to read and execute specific queries from the text file mentioned above.

### 🚚 Views_creation
This script converts the CSV file into a DataFrame, transfers the data into a database, and transforms every query listed in queries.txt into an Excel file with the resulting data.

## 🚀 How to Use
1. Run the Main script

`python Main.py`

2. Output
A new folder named `Queries_results` will be created, containing the resulting files generated by the transformation scripts.

⚠️ **Note**

**When adding or modifying a query in the text document, please ensure you follow the existing numbering format to avoid execution errors.**

## 🧪 Key Insights & Discussion
- The Nintendo Factor: Nintendo is ranked as the publisher with the highest revenues of all time, despite not having the highest number of releases. The Mario Bros. franchise remains a dominant force in these metrics.
- **Console Wars:** PlayStation 2 and 3 are identified as the most successful consoles, leading in both total sales and total releases.
- **Regional Trends:** NA, EU, and Rest of the World: Action and Sports genres dominate these markets.
- **Japan:** An interesting exception where Role-Playing (RPG) is the most successful genre and the Nintendo DS is the top-selling console.
- **The Peak Era:** For most publishers, the years between 2006 and 2008 represent the historical peak of the industry's profitabilit.
